## 4. アプリの技術構成

Rust 2021 / eframe・egui 0.34系のネイティブアプリ。WindowsとmacOS。OBSなどへ重ねる時計、ストップウォッチ、外部時刻同期・タイムコード出力が中心。

| 場所 | 役割 |
|---|---|
| `src/main.rs` | Settings、UI、時計とストップウォッチ、設定保存、終了制御、NativeOptions |
| `src/ntp.rs` | NTP |
| `src/ptp.rs` | PTP |
| `src/mtc.rs`, `src/ltc.rs` | タイムコード入力 |
| `src/mtc_out.rs`, `src/ltc_out.rs` | タイムコード出力 |
| `src/osc.rs` | OSC受信 |
| `src/tc.rs` | タイムコード共通処理 |
| `build.rs` | WindowsのEXEリソース埋め込み |
| `Cargo.toml` | features、依存関係、macOS bundle設定 |
| `deploy.sh` | Mac上でfull/appstore両版のuniversal bundle作成 |
| `appstore/` | App Store向け署名・パッケージ・メタデータ関連 |
| `third_party/winit/` | 既存のmacOS非公開API対処用vendor。今回未変更 |
| `docs/` | 公開ドキュメント・サイト・handoff |

features:
- 既定 `full-sources`: 外部時刻入力と `tc-out`。
- Mac App Store版: `--no-default-features --features tc-out`。
- releaseはWindowsのコンソールを表示しない。ビルド成果物名は `stream-clock.exe`、インストール時名は `StreamClock.exe`。
- Settingsに `minimize_on_close` があり、閉じる操作で終了せず最小化する場合がある。終了・入れ替え時には状態を確認する。
- ウィンドウ位置・設定が保存される。今回の復旧で設定を削除・初期化していない。

## 5. デザイン判断とファイル単位の変更

旧アイコンには時刻以外に無線、同期矢印、再生、スピーカー穴、JST表記があり、音響機器にも見える構成だった。時計を主役にするため5案を内蔵ImageGenで個別に生成。

`design/icon-concepts/2026-09-15/`:
- `01-minimal.png`: 青いミニマルな針時計
- `02-digital.png`: 大きい12:00表示
- `03-on-air.png`: 赤い点を組み込んだ時計
- **`04-stopwatch.png`: 採用原稿**
- `05-soft.png`: ミント色の柔らかな立体時計
- `README.md`: 各案の生成プロンプトと採用記録

Creative Productionのボードを直接表示できない当時のツール構成だったため、画像を会話に直接提示した。採用原稿はすでにGit管理されており、再生成や一時添付画像の探索は不要。

出力:
- `assets/icon/icon_1024.png`: 1024px PNG
- `assets/icon/app.ico`: 16/24/32/48/64/128/256px
- `assets/icon/AppIcon.icns`: 標準とRetinaの各サイズ
- `scripts/export-icon.ps1`: System.Drawingで高品質リサイズ。ICO/ICNSコンテナを書き出す。Windowsで実行。デザイン自体は変更しない。
- `src/main.rs` の `fn main`: ViewportBuilderに `eframe::icon_data::from_png_bytes(include_bytes!("../assets/icon/icon_1024.png"))` を使う `.with_icon(...)` を追加。
- `build.rs`: `cargo:rerun-if-changed=assets/icon/app.ico` を追加。
- macOSは既存のCargo bundle設定がICNSを参照するため設定変更不要。

既知の注意: build.rsはwinresourceの失敗をwarningにする既存仕様。そのためビルド成功だけでEXEアイコンの埋め込み成功と断定しない。Windows上でリソース抽出も確認する。
